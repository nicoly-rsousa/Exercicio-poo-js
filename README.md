# Exercícios de Fixação — TypeScript

Repositório destinado à prática e fixação dos conteúdos estudados em TypeScript.

## 🎯 Objetivo

Este projeto reúne exercícios práticos desenvolvidos durante os estudos, com o objetivo de reforçar conceitos de programação, TypeScript e desenvolvimento de sistemas.

Os exercícios serão adicionados gradualmente conforme novos conteúdos forem estudados.

## 📚 Conteúdos praticados

Entre os conteúdos abordados estão:

- TypeScript
- Tipagem
- Variáveis e constantes
- Funções
- Condicionais
- Estruturas de repetição
- Arrays
- Objetos
- Classes
- Programação Orientada a Objetos (POO)
- `constructor`
- `public` e `private`
- Métodos
- Interfaces
- Outros conceitos de desenvolvimento
